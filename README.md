  Python Task Manager
เป็นแอปพลิเคชันที่เขียนด้วยภาษา Python สำหรับการจัดการงานส่วนตัวผ่าน Command-Line Interface (CLI)  
ผู้ใช้สามารถเพิ่มงานใหม่ ดูงานทั้งหมด ทำเครื่องหมายว่างานเสร็จสิ้น ลบงาน และค้นหางานได้ง่ายผ่านเมนู CLI  
ข้อมูลทั้งหมดจะถูกเก็บในไฟล์ tasks.json

  วัตถุประสงค์
- ฝึกการใช้ Python สำหรับเขียนโปรแกรมเชิงโครงสร้าง
- ใช้การจัดการไฟล์ JSON เพื่อเก็บข้อมูล
- พัฒนา CLI แบบใช้งานได้จริง
- ฝึกการใช้งาน Git/GitHub สำหรับเวอร์ชันคอนโทรลและการจัดการโปรเจกต์

  วิธีติดตั้ง
ก่อนการรันโปรแกรมควรติดตั้ง Python ก่อน :
   - ดาวน์โหลดได้ที่ https://www.python.org
หลังจากดาวน์โหลดเสร็จ สามารถโคลนผ่าน :
  [https://github.com/your-username/python-task-manager.git](https://github.com/PKanta0/-Practical-Software-Engineering-Final-Project.git)
สามารถรันได้โดยการใช้คำสั่ง :
cd (name of folder)
และใช้คำสั่งเพื่อรันโปรแกรม :
python task_manager.py

  ฟีเจอร์หลัก
- เพิ่มงานใหม่: ใส่ชื่องาน คำอธิบาย และวันครบกำหนด
- ดูงานทั้งหมด: แสดงรายการงานทั้งหมด โดยแยก “ยังไม่เสร็จ” กับ “เสร็จแล้ว”
- ทำเครื่องหมายว่างานเสร็จสิ้น: ระบุรหัส ID ของงาน
- ลบงาน: ลบงานจากระบบด้วยรหัส ID
- ค้นหางาน: ค้นหาด้วยคำ หรือวันที่ครบกำหนด
- บันทึกข้อมูลเป็น JSON: งานทั้งหมดถูกบันทึกใน tasks.json อัตโนมัติ
